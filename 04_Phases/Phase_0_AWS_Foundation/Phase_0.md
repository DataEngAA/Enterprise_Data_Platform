# Phase 0 — AWS Platform Foundation

## Steps
1. Finalise requirements.
2. Create repository and branch strategy.
3. Configure secure AWS access.
4. Bootstrap Terraform state.
5. Build VPC and endpoints.
6. Create private EC2 development workstation.
7. Configure CloudTrail, CloudWatch, and Flow Logs.
8. Configure KMS and secrets foundation.
9. Configure budgets and shutdown strategy.
10. Add CI validation.
11. Test recreation and recovery.
12. Complete ADRs, runbooks, and interview notes.

## Completion
Infrastructure is reproducible; EC2 access is secure; credentials are not stored; logs and budgets work; the workstation can be recreated.
